# Gazza Perfumes

Luxury, modern, responsive frontend website for **Gazza Perfumes** — Fragrance of Heaven.

## Overview
- **Framework**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **Typography**: Cormorant Garamond & Plus Jakarta Sans
- **Catalog**: 7 inspired perfumes with official bottle & box packaging
- **Conversion Flow**: Direct one-click ordering to WhatsApp (+91 9048686786) with pre-filled messages
- **Offer**: Flat 60% OFF (₹799)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the assigned port) to view the website.

## Configuration

- **WhatsApp Phone Number**: Change `WHATSAPP_NUMBER` in `src/config/site.ts`.
- **Product Catalog & Prices**: Manage in `src/data/products.ts`.
- **Logo & Images**: Located in `public/images/`.
